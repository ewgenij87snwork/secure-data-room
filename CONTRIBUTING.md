# Contributing

This repository is primarily a reviewed take-home and portfolio artifact. Keep changes narrow,
verified, and traceable to a requirement or defect.

1. Open or reference a focused issue/requirement.
2. Create a small branch from the current integration branch.
3. Add or update tests before implementation where behavior changes.
4. Run `pnpm verify`.
5. Use Conventional Commits with a product-domain scope.
6. Complete the pull-request template with proof and screenshots when UI changes.

Do not add dependencies, public controls, or architectural layers without documenting the concrete
problem they solve and the simpler alternative considered.
